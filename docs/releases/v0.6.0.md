# ORCA Player v0.6.0: Phase 6, downloads

## What's new

- **Download engine.** A new `downloads` module runs downloads in the background with WorkManager and a foreground notification. It resumes after an app restart or a dropped connection, keeps going when you leave the app, and can split large files into up to four connections. It retries network and server errors with growing waits, asks the add-on for a fresh link when one expires, and pauses instead of failing when storage runs low.
- **Files and streams.** Ordinary files are saved where you choose: in Movies › ORCA Player › Downloads, in a folder you pick, or privately inside the app. HLS and DASH streams are saved inside the app with the quality, audio and subtitle tracks you choose, and play offline with only those tracks. A finished stream can be saved as one MP4 through the Tools queue.
- **Names.** Movies are named "Title (Year)" and episodes "Series S01E02 Episode title". Both templates can be changed in Settings. Subtitles are saved next to the video with the language in the name.
- **Where downloads start.** Every playable stream in the title's stream picker has a download button. Movies have a Download button, every episode has one, and "Download season" lets you choose episodes and a quality. The URL player, the player's Tools panel and links shared from other apps (Play or Download) can download too. The saving rule decides every time: DRM streams, sources that forbid saving, the Settings switch and Kids profiles all block a download, and the first download shows the saving reminder.
- **Downloads screen.** Active, Completed and Failed tabs with counts, storage used and free, progress with speed and time left, and per-download pause, resume, cancel, retry, Start now and reorder (drag or up and down). Completed downloads can be played, grouped by series, sorted, shared, opened with another app, opened in their folder, moved to private storage, saved as MP4, downloaded again or deleted. Playing an episode continues with the next downloaded one.
- **Smart downloads.** Turn it on for a series and the next episodes are fetched as you watch, keeping the number you set. A watched episode can be deleted automatically, after asking with a notification, or kept.
- **Notifications.** One progress notification with Pause all, Resume all and Cancel all, and separate notifications for finished and failed downloads, each of which opens the Downloads screen.
- **Home, Local and Tools.** Home shows a row of finished downloads. Local and Tools open the Downloads screen.
- **Settings.** A new Downloads section: where to save (with the system folder picker), downloads at once, multiple connections, speed limit, Wi-Fi only, charging only, a start time, retries, space to keep free, the two name templates, saving subtitles, finished notifications, smart download deleting and how many to keep, and whether Kids profiles may download. All of them are searchable and reset with their section, in English and Arabic.

## How it was tested

- Devices and Android versions: not tested on a device yet. The cloud build environment cannot run an emulator, and the owner asked for one APK at the end of all phases.
- CI run: unit tests (new: file names and templates, Content-Disposition names, range parsing and splitting, retry waits and which errors retry, the network and charging gate, the start-time window, the queue order, the smart download plan, the speed limiter, and restarting the store after the app is killed; plus all earlier tests), lint for both flavors and the standard-flavor licence check.
- Manual checks from the phase's "done when" list: pending a device.

## Known issues

- "Copy to device" for network shares arrives with Phase 9, when network shares are added.
- Android 15 limits how long a data sync foreground service may run each day. Very long download sessions may pause until the next day or until the app is opened.
- Saving a stream as MP4 depends on the codecs the device supports.
- A download over mobile data with "Wi-Fi only" on waits for Wi-Fi without asking.

## Decisions made where the prompt was silent

- HLS and DASH downloads always go inside the app, because the pieces of a stream are not one file another app could open. "Save as MP4" makes a single file when one is needed.
- Up to four connections are used only for files larger than 8 MB whose server accepts ranges.
- An expired link is replaced with the same stream from the same add-on when it can be found, otherwise the nearest quality. A replacement that differs in size starts again from the beginning and says so.
- Downloads are kept per profile. Kids profiles cannot download unless Settings allows it.
- Episodes are matched to downloads by the same key as resume positions, so the title page knows which episodes are downloaded.

## Install

- Phone, tablet or TV: ORCA-Player-standard-v0.6.0.apk
- Extended build (sideload only): ORCA-Player-extended-v0.6.0.apk
- SHA256SUMS.txt lets you check the files were not changed.
