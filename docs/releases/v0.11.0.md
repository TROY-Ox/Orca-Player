# ORCA Player v0.11.0: Phase 11, editors, backup and polish

## What's new

- **Navigation tabs editor.** Settings › Home › Navigation tabs. Reorder, hide and rename the tabs. The first shown tab opens when the app starts, and at least one tab always stays shown.
- **Player layout editor.** Settings › Player › Player layout. It shows a picture of the player with its six areas. On touch screens, long-press a control and drag it to another area. With a remote or keyboard, select a control and choose its area, size and order from the list. Hidden controls can be brought back. You can save layouts under a name and switch between them with one tap. Layouts saved by older versions get any new controls added in their default place.
- **Gesture map.** Settings › Gestures › Gesture map. Choose what each gesture does:
  - double tap on the start side, the middle or the end side
  - long press
  - swipe sideways
  - swipe up or down on either side
  - pinch

  The player follows the map. The existing on and off switches for each gesture still apply. Hidden on TV.
- **Tools order.** The Tools tab and the player's Tools panel keep their own editor, from the Tools tab.
- **Backup and restore.** Settings › Privacy › Backup and restore. One versioned file holds any of these:
  - settings, layouts and presets
  - addons with their order and settings
  - saved links and playlists
  - My List
  - profiles
  - network shares
  - history and resume positions (optional)

  Without a backup password, passwords, API keys, tokens and PINs are left out, and network shares can't be included. With a password, the file is encrypted with AES-256-GCM and a PBKDF2 key, and includes them. Restoring shows when and with which version the file was made, and lets you choose sections. It adds and updates rows and deletes nothing. The app then restarts to load everything.

## How it was tested

- Devices and Android versions: not tested on a device yet. The cloud build environment cannot run an emulator.
- Unit tests:
  - New: the backup file format (plain and encrypted round trips, a wrong or missing password, foreign files), which settings count as secrets, and the player layout edits (moving between areas, order within an area, completing older layouts).
  - The backup format and layout tests were also compiled and run locally.
- CI: this phase could not run on CI yet, because GitHub access for the build session stopped while it was being written. It must pass CI before merging.

## Known issues

- Extension repositories (extended build) and private-folder files are not in backups. The private folder's key lives in the device keystore and can't be moved.
- The player layout editor places controls by area and order. Spacing and opacity use the existing player settings.
- The two-finger tap is kept in the gesture map's model but isn't offered yet, because the player doesn't detect it.

## Decisions made where the prompt was silent

- Database tables are backed up column by column, together with the database version. Older files therefore restore into newer tables: columns the file lacks take their defaults.
- Restore merges rather than replaces. That way a partial restore never deletes data that is only on this device.
- Profiles restored from a backup without a password keep the PIN they already have on this device.

## Install

- No APK for this phase. The one APK for the owner is built from v1.0.0.
