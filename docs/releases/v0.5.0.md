# ORCA Player v0.5.0: Phase 5, add-ons and online sources

## What's new

- **Stremio add-on support.** A new `sources/stremio` module reads add-on manifests, catalogs (with paging, genres and search), title details with seasons and episodes, streams and subtitles. Parsing is lenient, so add-ons that send odd types or missing fields still work. `stremio://` links open the app and go straight to the install screen.
- **Add-ons tab.** Add an add-on by link or by pasting it, or pick one from the community directory. Before installing, a preview shows what it provides and warns about peer-to-peer streams, adult content and add-ons that must be configured first (Configure opens in a Custom Tab). The list has a health dot for each add-on, on/off switches, reordering by drag or with up and down buttons, filters, search, multi-select, and undo after removing. The whole list can be exported to and imported from a file or the clipboard.
- **Add-on details.** Stats, update checks with a summary of what changed, a switch per profile and for Kids profiles, a request timeout, and a catalog editor: rename, choose where each catalog shows (Home, Discover or hidden), reorder, pick the row style and default genre, and mark it as trending. Also configure, copy and share the link, view the raw manifest, and remove.
- **Home.** Rows from every enabled catalog in the order you set, loading more as you scroll near the end, a card to play a link, and a clear empty state when no add-on is installed.
- **Discover.** Pick an add-on and catalog, filter with its genre and other options, and browse a paged grid.
- **Search.** Searches every add-on at once and shows results as they arrive, merging the same title from different add-ons. Recent searches, trending titles, matches from your own files, and filters by type and by add-on.
- **Title page.** Backdrop and logo, details, trailer, seasons and episodes with progress. The stream picker lists every add-on's streams with quality, HDR, audio, size and source badges, sorts them by your rule, and filters by audio and subtitle language (remembered per title). External and YouTube links ask before leaving the app.
- **Automatic fallback.** When a stream fails or stalls for longer than a set time, the player moves to the next stream for the same title at the same position and says so. When it runs out, it asks the add-ons for fresh links once.
- **URL player.** Plays http, https and rtsp links with optional headers. It recognises HLS playlists and M3U lists, keeps a queue, saved links in folders and a history, and imports and exports M3U files. Pasting an add-on link offers to install it. A copied link can be offered when the app opens (a setting), using the clipboard description on Android 12 and newer and reading only while the app is in front.
- **Online subtitles.** Add-on subtitles plus OpenSubtitles with your own API key. When no subtitle in your language is found, the player can search after a few seconds and load the best match, with a pill to change it. "Search online" in the subtitle panel shows every result with its match type and downloads. Matching uses the file hash when the video is a local file.
- **Streaming engine.** Default and per-site HTTP headers and User-Agent, a disk cache for streams with a size you choose, the buffer length, and RTSP playback.
- **Settings.** A new Sources section (copied link detection, User-Agent, default headers, buffer, cache size, history length, add-on timeout, show unsupported streams, stream sort, preferred quality, auto-pick, fallback, retries and stall time) and subtitle auto-download and OpenSubtitles key under Subtitles. The key is stored as a secret and never shown. All of them are searchable and reset with their section, in English and Arabic.

## How it was tested

- Devices and Android versions: not tested on a device yet. The cloud build environment cannot run an emulator, and the owner asked for one APK at the end of all phases.
- CI run: unit tests (new: manifest parsing, URL building and encoding, catalog, meta and stream parsing, cache freshness and stale-on-error rules, paging with skip, stream badges for Torrentio-style names, and M3U and HLS detection; plus all earlier tests), lint for both flavors and the standard-flavor licence check.
- Manual checks from the phase's "done when" list: pending a device.

## Known issues

- RTMP links are not supported. The only RTMP library for Media3 ships native code whose 16 KB page alignment and licence could not be verified, so it was left out.
- A new stream cache size applies from the next video.
- OpenSubtitles works with an API key only; signing in to an account is not offered yet.
- The "Extensions" filter on the Add-ons tab is empty until Phase 8 adds extensions.
- Drag reordering is basic. The up and down buttons are the dependable way to reorder on TV.
- Continue Watching and My List rows arrive with Phase 7.

## Decisions made where the prompt was silent

- A title from any add-on resumes from the same place, because resume is keyed by the title and episode and not by the stream. The link itself is always fetched fresh.
- Equalizer and per-video settings for add-on titles are kept per title, so all episodes of a series share them.
- Add-on responses are cached on disk by type: catalogs and details for hours, streams for minutes. An old catalog is shown if the add-on is down, but an old stream link never is.
- Add-on update checks run at most once a day when the app opens, and never download anything without a tap.
- The User-Agent defaults to "ORCA Player".

## Install

- Phone, tablet or TV: ORCA-Player-standard-v0.5.0.apk
- Extended build (sideload only): ORCA-Player-extended-v0.5.0.apk
- SHA256SUMS.txt lets you check the files were not changed.
