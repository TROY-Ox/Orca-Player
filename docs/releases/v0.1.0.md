# ORCA Player v0.1.0: Phase 1, foundation

## What's new

- Project with `standard` and `extended` flavors (`com.troy.orcaplayer`, `.extended`, debug `.debug`), minSdk 26, targetSdk 36.
- TROY Enhanced Theme as a Compose module: all ten accents plus a custom colour (teal default), dark and AMOLED black, glass panels, Roboto, bundled Noto Sans Arabic and Roboto Mono, theme springs converted to Compose, lite motion tier on TV and low-RAM devices.
- Base components: buttons (one primary per screen, press scales to 0.97), 44 x 26 spring toggle, chips, alerts, inputs with the accent focus ring, glass panels with materialize, shimmer, empty, error and offline states, focus ring on every interactive element.
- Navigation shell: Home, Local, Addons, Search, Tools. Bottom bar on phones in portrait, rail in landscape and on tablets, wide side rail with initial focus on TV. Settings and profiles open from the avatar on every main tab.
- Settings with search (English and Arabic, ignores diacritics and hamza forms), reset per section, and a versioned DataStore schema with migrations.
- Design-early models: profiles (one default profile), PlayRequest, ContentSource, media identity keys, layout models (tabs, Home rows, player controls, gestures, tools), and the saving rule.
- Arabic with full RTL, per-app language that applies without restarting, Western or Arabic-Indic digits, and a setting to mirror the media timeline.
- Edge-to-edge, predictive back, cleartext allowed with a network security config, secrets and private folders excluded from backup, Licences screen.
- CI/CD: CI, Release, UI tests and Dependabot.

## How it was tested

- Devices and Android versions: built and unit-tested on GitHub Actions. No emulator or device run yet; the weekly UI test workflow covers Android 16 and a 16 KB page size image.
- CI run: see the pull request checks.
- Manual checks from the phase's "done when" list: still to do on phone, tablet, foldable and TV.

## Known issues

- Frosted glass is a stored setting, but real backdrop blur behind panels isn't drawn yet (Compose has no backdrop blur; it needs a library such as Haze, planned with the browsing work).
- Placeholder tabs only. The player and local files arrive in Phase 2.
- Only one profile; creating profiles, PINs and kids mode come in Phase 7.

## Decisions made where the prompt was silent

- Feature screens live in `:app` for Phase 1; `:feature:*` modules are split out as each feature gets real content.
- Versions follow the tested set of Google's Now in Android sample (AGP 9.3.2, Gradle 9.7.1, Kotlin 2.3.0, Compose BOM 2025.09.01). Dependabot raises newer ones weekly.
- In Arabic, the whole UI uses Noto Sans Arabic; in English, Roboto (Arabic letters in English UI fall back to the system Arabic font).
- Reduce motion and high contrast are on when either the in-app switch or the system setting is on.
- Releases are signed with a committed test key until the real key secrets are added.
- Custom accent picker uses hue and brightness sliders at fixed saturation.

## Install

- Phone, tablet or TV: ORCA-Player-standard-v0.1.0.apk
- Extended build (sideload only): ORCA-Player-extended-v0.1.0.apk
- SHA256SUMS.txt lets you check the files were not changed.
